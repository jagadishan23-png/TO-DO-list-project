# To-Do List App

A simple To-Do List application built using Python and Tkinter.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed

## Technologies Used
- Python
- Tkinter
- Git
- GitHub

1. Download or clone the project
2. Open the project folder
